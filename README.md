# Page.json

A page as data, not code.

Page.json is an open standard for describing UI pages as JSON trees. Just as MCP standardizes how agents call tools, Page.json standardizes how pages are described as data across applications.

It is:

- **Renderable** as a web page, mobile view, rich text article, modal, email, and more.
- **Producible** by humans, LLMs, visual editors, workflow outputs — anything that can write JSON.
- **Declarative**. Reuses your components. Safe to store, diff, version, and send. No embedded code, no `eval()`.

The format and component contracts live in [docs/components.md](./docs/components.md).
